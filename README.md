# .clab

A collection of C exercises, experiments, and questionable decisions.

## What is this?

An attempt to understand C beyond making the compiler shut up.

Pointers. Memory. Data structures. Undefined behavior.

The usual suspects.

## Objectives

- Understand memory, not just allocate it.
- Learn pointers without questioning reality.
- Figure out what the machine actually does.
- Write code that works for the right reasons.
- Survive undefined behavior.

## Repository Structure

```text
CLabratory/
├── main.c
└── README.md
```

The structure will evolve as the experiments get more complicated.

## Ground Rules

- Understand first. Memorize later.
- Every bug is a question waiting to be answered.
- If it compiles, that proves very little.
- If it runs, that proves even less.
- Undefined behavior is not a feature.

## Progress Log

Learning C, one mistake at a time.

Some experiments will work. Some will crash. Others will work perfectly for reasons nobody should trust.

That's the point.
